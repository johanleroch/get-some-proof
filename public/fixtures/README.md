# Fixture assets

Stand-ins for the development fixtures only (`/visual-evidence/*`, `/screens`,
`/kit`), never for the product.

`bumpr-logo.svg` is the logo of Bumpr, the fictional project every
authenticated screenshot is taken on: the symbol from the Bumpr lockup, set on
its black square so it reads as an uploaded project logo at 24px. Drop a
different file at the same path to change what those screenshots show.
