# Delete a workspace without recovery

Workspace Deletion requires an Owner session created within the previous five minutes, the exact Brand name, and a separate irreversible confirmation after independent data-export and eligible-video download offers. Confirmation atomically marks the Brand as deleting so its Collection Form, Public Wall, Embedded Wall, management mutations, and new uploads become unavailable before external cleanup begins. A leased Convex workflow stores the Stripe subscription identifiers plus minimal indexed deletion markers, schedules a watchdog for abandoned work, cancels each subscription with a stable idempotency key, deletes queued and attached Mux uploads/assets before their local records, and purges organization-scoped, billing-webhook, authorization, audit, storage, and Brand records in bounded steps. A Stripe webhook serialized before confirmation is purged, while one serialized after it is ignored, added to the cancellation markers, and wakes the workflow without recreating entitlement. Failed provider cleanup leaves public access closed, schedules bounded backoff, and exposes a manual retry, while completion retains only content-free deletion state for status, webhook suppression, and replay safety; no recovery window or retained Workspace copy exists, and a failed or abandoned export changes nothing.
