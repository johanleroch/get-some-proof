# Delete a workspace without recovery

Workspace Deletion requires an Owner session created within the previous five minutes, the exact Brand name, and a separate irreversible confirmation after independent data-export and eligible-video download offers. Confirmation atomically marks the Brand as deleting so its Collection Form, Public Wall, Embedded Wall, management mutations, and new uploads become unavailable before external cleanup begins. A resumable action stores the Stripe subscription identifiers, cancels each subscription with a stable idempotency key, deletes queued and attached Mux uploads/assets before their local records, and purges organization-scoped, billing-webhook, authorization, audit, storage, and Brand records in bounded batches. Failed provider cleanup leaves public access closed and exposes a retry, while completion retains only a content-free deletion tombstone for status and replay safety; no recovery window or retained Workspace copy exists, and a failed or abandoned export changes nothing.
