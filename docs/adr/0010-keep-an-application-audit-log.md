# Keep an application audit log

The application records immutable, organization-scoped audit events for invitations, membership and role changes, organization settings, and sensitive resource operations. This log complements rather than replaces the internal authorization-change audit maintained by convex-authz, because neither source alone describes both business actions and permission changes; only Owners and Admins may view the application log. Permanent Testimonial deletion is the privacy exception: the prior Testimonial event stream is deleted in bounded resumable batches and replaced by one immutable, content-free deletion event.
