# Use one once-editable public slug without redirects

The Brand name proposes a unique Public Slug used by both `/c/<slug>` and `/w/<slug>`; if it is unavailable, onboarding requires the Owner to choose another before creation. The Owner may change the Public Slug once, after which it becomes permanent; the former slug is released for immediate reuse, and old collection, wall, and embed URLs break without redirects. This deliberately favors a simple namespace over protecting an Owner from the consequences of the one explicit change.
