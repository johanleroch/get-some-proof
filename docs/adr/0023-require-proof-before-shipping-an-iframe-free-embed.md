# Require proof before shipping an iframe-free embed

The MVP embed must use the shared wall presentation without an iframe, with Shadow DOM as the preferred isolation mechanism and inherited host typography as an explicit behavior. A prototype must prove rendering, resizing, isolation, and font inheritance on WordPress, Webflow, Framer, and plain HTML before the production embed proceeds; if that proof fails materially, the product decision is reopened rather than silently substituting an iframe.
