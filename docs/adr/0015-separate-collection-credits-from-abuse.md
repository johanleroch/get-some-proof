# Separate lifetime collection credits from abuse

Free Collection Credits are consumed by valid completed Submissions and are not restored when genuine proof is archived or permanently deleted, preserving the intended lifetime limit. Used credits persist when the Workspace upgrades to Pro and if it later returns to Free. A Submission confirmed as Spam is quarantined and restores its credit, with abuse prevention on the public form and at most three automatic restorations per rolling 30 days before manual review. When one content type is exhausted, the Collection Form disables only that type; when both are exhausted, it reports that collection is temporarily closed without disclosing the Owner's plan. This accepts a small review path so an attacker cannot exhaust a Brand's plan and an Owner cannot turn ordinary deletion into unlimited free collection.
