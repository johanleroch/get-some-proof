# Widget fonts

Figtree and Caveat WOFF2 subsets are the same Google Fonts assets resolved by
Next.js for this repository on 2026-09-09. Their OFL licenses are included here.
The build embeds them so the sandbox does not depend on a third-party font
request or on ephemeral Next.js build paths. Gelica uses the existing approved
files under `src/app/fonts/gelica`; it is not duplicated in this directory.
